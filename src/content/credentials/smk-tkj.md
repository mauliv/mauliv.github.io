## 1. Vocational Engineering Foundation

Graduated with an academic average score of 85.3 / 100 from SMK Negeri 3 Yogyakarta, specializing in Computer Network Engineering.

The curriculum provided rigorous hands-on Layer 1 through Layer 4 infrastructure training:
* Physical Infrastructure: Structured UTP and optical fiber termination, OTDR link testing, and rack-mount server assembly.
* Network Topologies & Enterprise Routing: Subnet planning (VLSM), VLAN segmentation, inter-VLAN routing, and static and dynamic routing on Cisco and MikroTik hardware.
* Server Administration: Linux (Debian and Ubuntu) deployment, DNS and DHCP configuration, Apache and Nginx web serving, and SSH remote management.

---

## 2. Engineering Capstone: Network Attached Storage (NAS) Deployment with XigmaNAS

For the vocational engineering graduation capstone, designed, deployed, and bench-tested a local enterprise Network Attached Storage (NAS) system powered by XigmaNAS (FreeBSD-based ZFS architecture):
* Storage Pools & Parity: Configured software RAID storage pools utilizing ZFS to ensure high data integrity, automatic data scrubbing, and hardware fault tolerance.
* Network Protocol Sharing: Implemented Samba/SMB and NFS network shares with granular role-based access control (RBAC) across departmental user groups and laboratory workstations.
* Performance Benchmarking: Benchmarked read and write throughput across Gigabit Ethernet uplinks to validate concurrent multi-user file transfer stability and low-latency storage access.

---

## 3. Early Software Engineering: School-Wide E-Voting Platform

In August 2018, pioneered digital electoral governance for the school by architecting and launching the Online E-Voting System for Student Council (OSIS) and Vice-Principal elections:
* Production Domain: Deployed on the official school subdomain at `www.pemilos.skagata.sch.id`.
* Tech Stack: Native PHP and MySQL with an intuitive responsive web interface.
* Impact & Institutional Longevity: Replaced thousands of physical paper ballots with real-time digital voting across networked computer laboratories. The platform continued to be trusted and actively utilized by the school for years after graduation, as formally documented in the school's official coverage:

> *"Proses pemungutan suara Pemilihan Ketua OSIS dilakukan secara daring melalui aplikasi yang dapat diakses pada laman www.pemilos.skagata.sch.id . Aplikasi ini merupakan karya dari Alifah Maulidin Nur Ikhsan, alumni TKJ lulusan tahun 2019. Aplikasi ini pertama ksli diciptakan semasa belajar di SMK Negeri 3 Yogyakarta."*  
> *(English translation: "The Student Council Chairperson election voting was conducted online via the application accessible at www.pemilos.skagata.sch.id. This application is the work of Alifah Maulidin Nur Ikhsan, a 2019 Computer Network Engineering alumnus, first created during his studies at SMK Negeri 3 Yogyakarta.")*  
> (Source: [SMK Negeri 3 Yogyakarta Official Portal, April 2021](https://smkn3jogja.sch.id/2021/04/pelantikan-pengurus-osis-smk-n-3-yogyakarta-masa-bakti-tahun-2021/))

This early high-concurrency production deployment established the foundational database architecture, atomic vote commitment, and tamper-evident auditing workflows that would later evolve into UNY's enterprise-scale campus e-voting engine ([pemilwa.uny.ac.id](/it/pemilwa-evoting)).
