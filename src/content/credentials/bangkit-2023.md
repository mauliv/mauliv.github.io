## Program

Bangkit Academy 2023 (Cloud Computing Path): the 6-month, 900-hour Kampus Merdeka career readiness program led by Google, GoTo, and Traveloka (16 February to 31 July 2023, Student ID `C288DSX2712`).

## Curriculum

Hands-on training in Google Cloud Platform (GCP), cloud architecture, Linux systems administration, backend API development, soft skills, and English for professionals.

## Context

The cloud and data layer of the full-spectrum stack, paired with Google Cloud BigQuery coursework (2022) and Google System Administration training (2023). Official cohort enrollment is corroborated by the **Letter of Acceptance** (`BA23-1/LoA/XXIII-02/C288DSX2712`, issued 14 February 2023).
